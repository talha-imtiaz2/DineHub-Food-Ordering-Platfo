# 🍽️ Dine Hub

Dine Hub is a modern restaurant management and food ordering platform designed to provide customers with a seamless dining experience.

## 🚀 Features

- User Authentication
- Browse Food Menu
- Search & Filter Dishes
- Online Food Ordering
- Reservation Management
- Responsive Design
- User-Friendly Interface
- Secure Data Management

## 🛠️ Technologies Used

Frontend:
- HTML5
- CSS3
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB
